# agentkit-shopify-demo

Agent skills for the agentic Shopify purchase Lift Off demo, using [AgentKit](https://docs.world.org/agents/agent-kit) to unlock exclusive human-only discounts.

## Setup

1. Install both skills in the `skills/` directory into your agent's harness.
2. Connect your agent to the Shopify Storefront MCP (defined in `.mcp.json`).
3. Give your agent an Ethereum private key (you can just ask it to generate one) and register its address in the AgentBook as described in the [AgentKit docs](https://docs.world.org/agents/agent-kit/integrate).

## Flow

To trigger the flow, you can simply ask your agent to help you purchase the human-only hat, providing a link to the product listing.
